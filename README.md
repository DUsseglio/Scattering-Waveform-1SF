# Scattering waveform results

This repository contains results discussed in the paper **“Analytical
Time-Domain Waveforms for Black-Hole Scattering in the Self-Force Expansion”**
by **Chris Kavanagh, Julio Parra-Martinez and Davide Usseglio**.

The repository will be made public together with the paper. Before that release,
access is restricted to authorized collaborators.

## Result collections

- [`Scattering-Waveform-SF/10PM-10PN`](Scattering-Waveform-SF/10PM-10PN/):
  waveform multipoles from `l=2` through `l=22`, through 10PM and the usual
  10PN cutoff relative to the leading `l=2` order, in the non-minimal basis.
- [`Scattering-Waveform-SF/Quadrupole:10PM-20PN`](Scattering-Waveform-SF/Quadrupole:10PM-20PN/): reserved for the quadrupole
  results through 10PM and 20PN.

Each collection contains its own README describing the organization and
loading instructions. Result files are being prepared for upload.
