# Quadrupole: 10PM–20PN

This collection is reserved for quadrupole (`l=2`) results through 10PM and
20PN discussed in **“Analytical Time-Domain Waveforms for Black-Hole Scattering
in the Self-Force Expansion”** by **Chris Kavanagh, Julio Parra-Martinez and
Davide Usseglio**.

Result files and loading instructions will be added when ready.
